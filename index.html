Store hero thumbnails

Upload the Excel (or CSV) file with a hero image URL and a store ID on each row. Every store renders as a thumbnail card so you can scan the whole week's ads at a glance, spot broken images, and see which stores share the same creative.

Drop your file here

.xlsx, .xls or .csv — parsed right in your browser, nothing is uploaded anywhere.

Expected format

Two columns — the hero image URL and the store ID. Column names and order don't matter; the tool finds the URL column automatically. It matches the weekly-ad file you're already using:
